# Патч №5 v2 — проверка каждой буквы + 3 попытки + жизни + экономика

Этот ZIP **полностью заменяет Patch 05 v1**. Внутри находятся файлы Patch 05 v1 и новая аддитивная миграция `005_letter_attempts.sql`. Применяется поверх `main` **после слияния PR №4**. Не накладывай на старую ветку #3.

## Новые правила

- Начало: 30 монет, 5 жизней, 2 подсказки (существующие игроки не сбрасываются).
- Каждая вводимая буква проверяется на сервере немедленно. Неверная буква **не сохраняется** в клетке, но уменьшает попытки: 3 → 2 → 1 → 3 и списывает 1 жизнь на третьей ошибке.
- **Правильная** буква закрепляется **только в указанной клетке**. Одинаковый номер в других клетках не заполняется автоматически.
- Попытки (всего три ошибки до потери жизни) хранятся в `puzzle_attempts.mistakes`, прогресс сохраняется между запусками.
- При 0 жизней введение букв и использование подсказок запрещено (`NO_LIVES`). Блокнот, просмотр уровня и кошелька доступны.
- 1 жизнь восстанавливается каждые **30 минут** до максимума 5; время серверное.
- Последняя правильная буква **автоматически завершает уровень**, начисляет награду один раз и открывает бонус «Кто это сказал?». Подсказка, открывшая последнюю клетку, тоже завершает уровень.
- Правильный ввод в уже решённую клетку повторно не нужен; клетка блокируется. Для сетевых повторов **каждый новый ввод обязан иметь UUID `requestId`**, причём повтор одного и того же ID не снимает попытки снова.
- Магазин монет: 1 жизнь = 50 монет, 3 жизни = 120; 1 подсказка = 45, 3 = 120. Прочие награды как в Patch 05 v1.
- Старый `POST /attempts/:id/check` более не используется и возвращает HTTP 410 `LETTER_VALIDATION_ONLY`.

**Платный магазин и вознаграждаемая реклама:** данный патч реализует только **внутриигровые монеты**. Настоящих рекламных/платёжных начислений пока **нет**, никакого небезопасного публичного endpoint `grant-life` тоже нет. Для реальных наград позже потребуется серверная проверка рекламных колбэков или чеков покупки, защита от повторных начислений и привязка аккаунта.

Сначала проверь `git status --short`. Если Patch 05 v1 **ещё не устанавливал**, то после слияния PR #4:

```powershell
cd D:\Bloger\BlogerGrameGame-backend
git switch main
git pull --ff-only origin main

```

Если Patch 05 v1 **уже находится в локальной ветке `feat/05-economy`**, просто оставайся на ней. НЕ создавай ещё одну ветку поверх незакоммиченных файлов и НЕ откатывай БД.

Распакуй **содержимое ZIP** в корень репозитория, заменяя совпадающие файлы. Не удаляй `.env`, `backups`, данные PostgreSQL или Docker volume.

```powershell

powershell -ExecutionPolicy Bypass -File .\scripts\backup-local.ps1
npm ci
npm run db:migrate
npm run db:migrate
npm run content:import-drafts
npm test
npm run game:smoke

```

В первый запуск должны быть `[applied] 004_economy.sql` и `[applied] 005_letter_attempts.sql` (либо `[skip] 004_economy.sql`, если уже был установлен Patch 05 v1). **Повторный запуск** мигратора должен пропустить все применённые файлы. Если мигратор сообщает о несовпадении checksum, **ничего не правь в `schema_migrations`** — покажи лог.

`npm test`: 48 тестов; два smoke-теста требуют **настоящую локальную PostgreSQL** и импортированные 42 черновые цитаты. Они создают временных гостей и удаляют только свои тестовые записи.

Проверяй, чтобы в staged не оказалось `.env`, токенов, `backups` или `node_modules`. PR в `main`, проверка CI до слияния.

## API

`PATCH /api/v1/game/attempts/:id/cells/:position`:

```json
{"letter":"Г","requestId":"07fce1e8-9ccb-4d81-84c4-d2a0e754610f"}
```

Для каждого **нового нажатия** используй новый UUID. При сетевом retry используй **тот же UUID и ту же букву и позицию**. `letter:null` больше не нужен: правильные буквы закрепляются, неверные вообще не записываются.

Пример неудачной буквы:

```json
{"correct":false,"position":5,"mistakes":1,"triesRemaining":2,"lostLife":false,"locked":false,"wallet":{"coins":30,"lives":5,"hints":2,"maxLives":5,"maxHints":20,"lifeRegenMinutes":30,"nextLifeAt":null}}
```

Правильная буква возвращает `correct:true`, заполненную `cell` и `solved:false/true`. При `solved:true` дополнительно возвращаются `rewardCoins`, `flawless`, `bonusOptions`, `wallet`. До разгадки правильная буква для **неверного** ввода не раскрывается.

Повтор `requestId` возвращает предыдущий результат с `replayed:true`; повтор ID с изменённым вводом — HTTP 409 `REQUEST_ID_CONFLICT`.

См. `docs/ECONOMY.md` и `docs/GAME_API.md`.

## Ограничения

- Только localhost, **не для публичного продакшена**.
- Все 42 цитаты остаются черновиками, права на медиа и дословность не подтверждены.
- Уже запущенные старые попытки могут содержать буквы из прежней свободной системы ввода; они не удаляются. Такие клетки можно исправлять новым валидируемым вводом.
